## 3. 当前记录语义

- 历史记录展示保存当时的结果。
- 继续使用只恢复允许的历史输入，并按当前规则重新计算。
- 新计算不会改写旧快照。
- 新结果需要用户再次明确保存。
- 行动和复盘关联原快照，不回写历史结果。
- 记录闭环不依赖旧 AI Report 管线。

## 4. 当前身份边界

- 当前身份主要跟随同一浏览器中的匿名身份 Cookie。
- 邮箱目前不是登录凭证，不代表跨设备恢复或账户找回。
- 不得向用户承诺尚未实现的登录、云同步、找回或跨设备合并能力。

## 5. 当前关系盘个性化研究

已经完成：

- 关系盘1.0个性化基线审计；
- 21个虚构对照案例和七维评分；
- 1.0基线测评；
- 个性化推理契约；
- 隔离原型；
- 22个独立留出案例复核。

独立复核最终决策：

`ADJUST`

已经证明：

- 结构化现实问题可以改变优先级和行动意图；
- 现实限制可以改变参与方式、渠道、时长和完成标准；
- 安全路径可以在普通关系建议前短路；
- 原型不是只适配原21个案例；
- 技术上的确定性个性化可行。

尚未证明：

- “现实问题—盘面证据”映射具有足够专业语义依据；
- 盘面证据为用户提供了真实而非装饰性的额外价值；
- 用户愿意并能正确理解新增结构化输入；
- 原型能够提高真实帮助感、行动完成率或关系结果；
- 当前方案适合真实用户测试或生产接入。

当前主要问题：

- 六类现实问题几乎总能从通用证据白名单中取得十神、五行或日支证据；
- 正常路径不容易自然进入 `plate_evidence_limited`；
- 存在“盘面事实真实，但与当前现实问题的相关性没有得到证明”的情况；
- 传统结构事实与现代产品解释假设仍需更严格的语义准入。

## 6. 当前允许的关系盘研究范围

允许：

- 继续使用虚构案例；
- 调整隔离评价中的盘面证据语义准入；
- 区分直接证据、辅助参考和不采用；
- 允许无盘面证据的诚实降级；
- 复测失败留出案例和完整回归；
- 进行不接触真实数据的小白理解审查。

当前禁止：

- 接入生产关系盘；
- 增加真实用户关系处境表单；
- 保存安全状态或关系敏感信息；
- 修改生产快照协议；
- 宣称关系盘2.0已成立；
- 开展中国大陆真实敏感数据测试；
- 用大模型处理真实关系处境。

## 7. 下一项研究方向

下一项最小研究方向是：

> 修正盘面证据语义准入，让盘面事实默认可以不参与现代关系问题解释；只有具备明确、克制、可说明桥梁的证据才进入输出，没有合格证据时自然降级。

修正原则：

- 用户确认的现实问题决定主问题和行动方向；
- 盘面事实不得证明现实事件发生；
- 盘面证据不负责判断谁对谁错；
- 盘面证据可以作为有限观察角度，但不强行决定行动；
- 无证据结果可以仍然有现实行动；
- 不为了保持“风水感”强行加入术语。
